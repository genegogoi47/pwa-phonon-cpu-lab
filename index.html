Prototype notes

This lab forces the Blixt Phonon CPU/WebAssembly backend. It does not use MediaPipe or JSPI. The model and its voice assets are cached by the library in browser Cache Storage. The application shell is cached separately by the PWA service worker.

CPU performance on iPhone 11 and older devices is not guaranteed. Test generation speed, heat, memory and background playback on each target device.
